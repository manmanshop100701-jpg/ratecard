FAQ

Sering Ditanyain 🤔

Berapa lama pengerjaan satu project?
Normalnya 3–7 hari kerja tergantung kompleksitas dan antrian. Butuh cepat? Ada add-on express 1×24 jam (+50%).
Bagaimana sistem pembayarannya?
DP 50% di awal sebagai tanda jadi, sisanya dilunasi saat preview final disetujui dan sebelum file dikirim. Pembayaran via transfer bank atau e-wallet.
Apakah bisa request revisi?
Tentu! Setiap paket sudah termasuk kuota revisi (lihat rate card). Revisi minor seperti ganti teks/warna cepat kok. Ganti konsep total dihitung project baru ya.
File apa saja yang saya terima?
Desain: file siap pakai (PNG/JPG/PDF). Video: file MP4 kualitas tinggi sesuai platform. Source file (.psd/.ai/.fig/project file) tersedia sebagai add-on.
Apakah ada paket langganan bulanan?
Ada! Untuk kebutuhan konten rutin (feed sosmed, reels mingguan, dll.) harga langganan lebih hemat dibanding satuan. Hubungi saya untuk penawaran custom.
